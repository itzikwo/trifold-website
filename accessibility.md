## Conformance level and standard

This website is built and maintained to meet the requirements of Israel’s Equal Rights for Persons with Disabilities (Service Accessibility) Regulations, 2013, in line with Israeli Standard IS 5568 for web content accessibility, which adopts the W3C’s WCAG 2.0 / 2.1 Level AA guidelines.

## What we have done

- Correct semantic structure (landmarks, a main-content region, and ranked headings) for navigation with assistive technology.
- All interactive components are fully operable by keyboard alone.
- A “skip to content” link and a clearly visible focus indicator during keyboard navigation.
- Colour contrast of at least 4.5:1 for normal-size text.
- Alternative text for meaningful images, and decorative graphics hidden from screen readers.
- Respect for the user’s reduced-motion preference.
- Content remains reachable and available even when JavaScript is disabled.

## Accessibility widget

An accessibility widget is embedded on this site, allowing display adjustments such as larger text, higher contrast, greyscale, highlighted links, a larger cursor, focus highlighting, and stopped animations. The widget is an add-on only — the substantive accessibility of this site comes from the site’s own code being built to the standard.

## Known limitations

We work to continuously improve the accessibility of the site. Even so, some elements may not yet be fully accessible — for example placeholder images and illustrations, downloadable files (such as PDF documents), and third-party content. If you come across an element that is not accessible, please contact us and we will address it as soon as we can.

## Contact us about accessibility

If you encounter an accessibility problem on the site, or would like to request an adjustment, contact our accessibility coordinator. When contacting us, it helps to include the address of the page where the problem occurred, a description of the problem, and the browser and assistive technology you were using.

### רמת ההנגשה ותקן

אתר זה נבנה ותוחזק כך שיעמוד בדרישות תקנות שוויון זכויות לאנשים עם מוגבלות (התאמות נגישות לשירות), התשע"ג–2013, ובהתאם לתקן הישראלי ת"י 5568 להנגשת תכנים באינטרנט, המאמץ את הנחיות WCAG 2.0/2.1 ברמה AA של ארגון ה‑W3C.

### מה נעשה באתר לצורך הנגשה

- מבנה סמנטי ותקין (אזורי ניווט, תוכן ראשי וכותרות מדורגות) לניווט באמצעות טכנולוגיות מסייעות.
- ניתן להפעיל את כל הרכיבים האינטראקטיביים באמצעות המקלדת בלבד.
- קישור "דלג לתוכן" וסימון מוקד ברור ונראה בעת ניווט במקלדת.
- ניגודיות צבעים העומדת ביחס של 4.5:1 לפחות עבור טקסט רגיל.
- טקסט חלופי לתמונות משמעותיות, והסתרת גרפיקה עיטורית מקוראי מסך.
- התאמת התנהגות האתר להעדפת "צמצום תנועה" של המשתמש.
- התוכן נשאר נגיש וזמין גם כאשר JavaScript אינו פעיל.

### רכיב הנגשה

באתר מוטמע רכיב הנגשה המאפשר התאמות תצוגה (כגון הגדלת טקסט, ניגודיות והדגשת קישורים). רכיב זה מהווה תוספת בלבד; ההנגשה המהותית מבוססת על התאמת קוד האתר עצמו לתקן.
